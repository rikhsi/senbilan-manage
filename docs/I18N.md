# Internationalization (i18n)

Stack: **[@jsverse/transloco](https://jsverse.github.io/transloco/)** (+ locale / messageformat packages).

Locales (see `AppConfig`):

| Code | Language          |
| ---- | ----------------- |
| `ru` | Russian (default) |
| `en` | English           |
| `uz` | Uzbek             |

Configured in `apps/*/src/environments/environment*.ts` as `defaultLocale` / `availableLocales`.

## Rules

1. **No hardcoded user-facing strings** in templates or TypeScript UI code.
2. Use Transloco pipes / `TranslocoService` / typed helpers from `@senbilan/shared/i18n`.
3. Keep keys **stable** and **scoped** — never invent one-off English sentences in components.
4. Run `npm run i18n:check` before merging (parity across `ru` / `en` / `uz`).

## Scopes

Prefer one scope per feature (or shared domain):

| Scope           | Typical owner                                                |
| --------------- | ------------------------------------------------------------ |
| `common`        | Shared buttons, validation, empty states                     |
| `auth`          | Login / session                                              |
| `users`         | Users feature                                                |
| `roles`         | Roles feature                                                |
| `permissions`   | Permissions                                                  |
| `dashboard`     | Dashboard                                                    |
| `settings`      | Settings                                                     |
| `notifications` | Notifications                                                |
| `profile`       | Profile                                                      |
| `ds`            | Design-system labels (select, table, pagination) when needed |

Key shape: `scope.key.nested` — e.g. `users.create`, `users.status.active`.

Load scopes lazily with the feature route when possible; register providers from `@senbilan/shared/i18n`.

## Templates

```html
<button app-button variant="primary">{{ 'users.create' | transloco }}</button>
```

Or bind a scoped translator in the component and call `t('create')`.

## Design-system components

DS components that need copy (select placeholders, table a11y labels, confirm dialogs) accept **label inputs** or i18n keys from the caller — they must not hardcode Russian/English.

## Checklist for PRs

- [ ] New UI text has keys in **ru**, **en**, and **uz**
- [ ] No raw sentences in `.html` / `.ts` UI
- [ ] `npm run i18n:check` passes

## Tooling

```sh
npm run i18n:check          # locale parity + template hardcoded-text scan
npm run i18n:unused         # optional unused-key report (heuristic, warn-only)
```

ESLint `@senbilan/no-hardcoded-text` / `@senbilan/no-hardcoded-text-ts` start as
**warn**. Escape hatch:

```ts
// eslint-disable-next-line @senbilan/no-hardcoded-text-ts -- intentional demo copy
```

```html
<!-- eslint-disable-next-line @senbilan/no-hardcoded-text -->
```

See `tools/eslint-rules/README.md`.
